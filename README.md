## 📄 Abstract
This project aims to build an advanced monitoring ecosystem for **Flask**-based micro-web applications. Unlike traditional logging systems, this architecture leverages **Grafana Loki** to transform unstructured logs into dynamic metrics and real-time insights.

---

## 🚀 Key Features Highlights
* **Comprehensive System Observability:** Bridging the gap between application-level API requests and underlying database interactions to ensure full-stack visibility.
* **Advanced Performance Analytics:** Utilizing statistical aggregations to monitor actual system bottlenecks and real user experience, moving beyond basic monitoring metrics.
* **Scalable Telemetry Architecture:** Designed to efficiently parse and manage high-cardinality log data within a Kubernetes ecosystem, ensuring stable and responsive dashboards under load.

---

## 🛠️ Tech Stack
* **Backend:** Python / Flask
* **ORM:** SQLAlchemy
* **Infrastructure:** Kubernetes (Minikube)
* **Observability Suite:** Grafana, Prometheus, Loki, Promtail
* **Query Language:** LogQL (Loki Query Language), PromQL
